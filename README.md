# 繳費管理 Payment Reminder 使用說明

# 版本：v28／IndexedDB + Google Drive 雲端備份 + 桌機彈窗修正

# 

# ============================================================

# 一、這個 App 是做什麼用的？

# ============================================================

# 

# 「繳費管理 Payment Reminder」是一個本機端帳單管理工具，可用來記錄信用卡、水電費、電信費、保險費、訂閱費、房租、貸款等各類帳單，並協助你追蹤繳費截止日、提醒天數、繳費狀態與繳費紀錄。

# 

# 本 App 支援 PWA，可加入手機或電腦主畫面使用；資料主要儲存在目前瀏覽器的 IndexedDB，也就是「本機瀏覽器資料庫」。舊版 localStorage 資料會在第一次開啟時自動搬移到 IndexedDB。

# 

# 重要提醒：

# 1\. 資料主要存在目前瀏覽器的 IndexedDB；你可以手動匯出 JSON，也可以手動備份到 Google Drive。

# 2\. Google Drive 雲端備份需要先設定 OAuth Client ID，並在 Google Cloud 啟用 Google Drive API。

# 3\. 帳號密碼備忘區只適合記錄繳費相關帳號或提示，不建議存放非常重要的正式密碼。

# 4\. 若要保存重要密碼，仍建議使用專業密碼管理器。

# 

#

# 二、主要分頁介紹

# ============================================================

# 

# 本 App 分成四個主要分頁：

# 1\. 帳單

# 3\. 紀錄

# 

# 4\. 設定

# 手機版會以底部導覽列顯示分頁，電腦版則會在上方顯示分頁按鈕。

# 三、帳單分頁使用說明

# ============================================================

# 

# 帳單分頁是最主要的使用區域，可用來新增帳單、查看未繳帳單、篩選資料與標記已繳。

# 

# \------------------------------------------------------------

# 1\. 摘要統計

# \------------------------------------------------------------

# 

# 帳單頁上方會顯示三個統計：

# 

# 1\. 未繳筆數

# &#x20;  顯示目前尚未繳費的帳單數量。

# 

# 2\. 提醒中

# &#x20;  顯示已進入提醒天數範圍內的帳單數量。

# 

# 3\. 本期未繳合計

# &#x20;  顯示目前未繳帳單的應繳金額合計。

# 

# 若某筆帳單金額尚未輸入，會以 0 元計算，畫面會顯示「待輸入」。

# 

# \------------------------------------------------------------

# 2\. 新增帳單

# \------------------------------------------------------------

# 

# 在「新增帳單」區塊輸入資料後，按下「儲存」即可建立一筆帳單。

# 

# 可填寫欄位包含：

# 

# 1\. 帳單類型

# &#x20;  可選擇信用卡、水電費、電信費、保險費、訂閱費、房租、貸款、其他。

# 

# 2\. 單位 / 銀行名稱

# &#x20;  例如：中國信託、台電、中華電信、國泰人壽等。

# 

# 3\. 帳單名稱

# &#x20;  例如：LINE Pay 卡、家用電費、手機門號、保險年繳等。

# 

# 4\. 帳單日

# &#x20;  帳單產生或計算的日期。

# 

# 5\. 繳費截止日

# &#x20;  最晚需要完成繳費的日期。

# 

# 6\. 應繳金額

# &#x20;  可輸入本期應繳金額。此欄位允許空白，空白時會顯示「待輸入」。

# 

# 7\. 最低應繳金額

# &#x20;  可記錄信用卡最低應繳金額，非信用卡帳單可視需求留空或填 0。

# 

# 8\. 繳費方式

# &#x20;  可選擇手動繳費或自動扣繳。

# 

# 9\. 帳單模式

# &#x20;  可選擇「循環」或「手動」。

# 

# 10\. 提前提醒天數

# &#x20;  例如填 3，代表截止日前 3 天開始進入提醒中狀態。

# 

# 11\. 繳費帳戶備註

# &#x20;  可填寫扣款帳戶、轉帳帳號、超商代碼提示等資訊。

# 

# 12\. 備註

# &#x20;  可填寫其他提醒，例如「本期有分期」、「記得確認自動扣款」、「帳單金額待確認」。

# 

# \------------------------------------------------------------

# 3\. 帳單類型說明

# \------------------------------------------------------------

# 

# 目前支援以下類型：

# 

# 1\. 信用卡

# &#x20;  適合管理信用卡帳單、最低應繳與繳費截止日。

# 

# 2\. 水電費

# &#x20;  適合管理水費、電費或瓦斯費。

# 

# 3\. 電信費

# &#x20;  適合管理手機費、網路費、門號費。

# 

# 4\. 保險費

# &#x20;  適合管理月繳、季繳、半年繳或年繳保費。

# 

# 5\. 訂閱費

# &#x20;  適合管理串流平台、雲端空間、軟體訂閱等費用。

# 

# 6\. 房租

# &#x20;  適合管理每月租金或管理費。

# 

# 7\. 貸款

# &#x20;  適合管理房貸、車貸、信貸、分期付款。

# 

# 8\. 其他

# &#x20;  適合放不屬於以上分類的帳單。

# 

# \------------------------------------------------------------

# 4\. 帳單模式：循環 / 手動

# \------------------------------------------------------------

# 

# 每一筆帳單都可以獨立設定為「循環」或「手動」。

# 

# 1\. 循環：已繳後建立下期

# &#x20;  適合每個月或固定週期都會出現的帳單。

# &#x20;  例如：常用信用卡、手機費、房租、訂閱費。

# 

# &#x20;  當你按下「已繳並建立下期」後，系統會：

# &#x20;  - 將本期帳單加入繳費紀錄。

# &#x20;  - 自動把帳單日與截止日往後推一個月。

# &#x20;  - 產生下一期未繳帳單。

# 

# 2\. 手動：已繳後不建立下期

# &#x20;  適合不是每個月都會有的帳單。

# &#x20;  例如：少用信用卡、偶爾才出現的費用、不固定帳單。

# 

# &#x20;  當你按下「標記已繳」後，系統會：

# &#x20;  - 將本期帳單加入繳費紀錄。

# &#x20;  - 不會建立下一期。

# &#x20;  - 該筆帳單會變成已繳，不再列入未繳統計。

# 

# 建議用法：

# \- 常用、固定會繳的項目，設為「循環」。

# \- 很少用、不一定會有帳單的項目，設為「手動」。

#

# 5\. 帳單清單操作

# 

# 每一筆帳單卡片會顯示：

# 

# 1\. 帳單類型

# 2\. 單位 / 銀行名稱

# 3\. 帳單名稱

# 4\. 帳單日

# 5\. 繳費截止日

# 6\. 應繳金額

# 7\. 最低應繳金額

# 8\. 繳費方式

# 9\. 帳單模式

# 10\. 提前提醒天數

# 11\. 繳費帳戶備註

# 12\. 備註

# 13\. 目前狀態

# 卡片上的常見按鈕：

# 

# 1\. 已繳並建立下期

# &#x20;  只有循環模式帳單會顯示。按下後會記錄繳費，並產生下一期。

# 

# 2\. 標記已繳

# &#x20;  只有手動模式帳單會顯示。按下後只記錄繳費，不產生下一期。

# 

# 3\. 上傳 Google 日曆

# &#x20;  會產生 .ics 行事曆檔案，可加入手機或電腦行事曆提醒。

# 

# 4\. 編輯

# &#x20;  將該筆資料帶回表單，可修改內容後重新儲存。

# 

# 5\. 刪除

# &#x20;  刪除該筆帳單。刪除前會跳出確認提示。

# 

# \------------------------------------------------------------

# 6\. 搜尋與篩選

# \------------------------------------------------------------

# 

# 帳單清單上方可進行搜尋與篩選：

# 

# 1\. 關鍵字搜尋

# &#x20;  可用銀行名稱、帳單名稱或帳單類型搜尋。

# 

# 2\. 類型篩選

# &#x20;  可選全部類型、信用卡、水電費、電信費、保險費、訂閱費、房租、貸款、其他。

# 

# 3\. 狀態篩選

# &#x20;  可選全部狀態、未繳、已繳、提醒中、已逾期。

#

# 四、帳號分頁使用說明

# ============================================================

# 

# 帳號分頁用來記錄繳費相關帳號、用戶編號、密碼備忘、繳費網址與備註。

# 

# \------------------------------------------------------------

# 1\. 新增帳號密碼備忘

# \------------------------------------------------------------

# 

# 點開「新增 / 編輯帳號密碼」後，可填寫：

# 

# 1\. 服務名稱

# &#x20;  例如：台電、台水、中華電信、信用卡網銀、保險公司。

# 

# 2\. 帳號 / 用戶編號

# &#x20;  例如：用戶電號、手機門號、會員帳號、登入帳號。

# 

# 3\. 密碼 / 備忘

# &#x20;  可填寫密碼提示、簡短備忘或實際密碼。

# &#x20;  若是重要密碼，建議不要直接存入本 App。

# 

# 4\. 繳費網址

# &#x20;  可填寫官方繳費網址或登入頁網址。

# 

# 5\. 備註

# &#x20;  可填寫繳費方式、注意事項、帳單查詢位置等。

# 

# 填寫後按下「儲存帳號」即可新增。

# 

# \------------------------------------------------------------

# 2\. 帳號清單操作

# \------------------------------------------------------------

# 

# 帳號清單採用收合式卡片，避免資料太長。

# 

# 預設只會看到：

# \- 服務名稱

# \- 帳號 / 用戶編號

# \- 點開查看

# 

# 點開後可使用：

# 

# 1\. 複製帳號

# &#x20;  將帳號或用戶編號複製到剪貼簿。

# 

# 2\. 複製密碼

# &#x20;  將密碼或備忘欄位內容複製到剪貼簿。

# 

# 3\. 顯示 / 隱藏密碼

# &#x20;  切換密碼內容是否顯示。

# 

# 4\. 開啟繳費網站

# &#x20;  若有填寫網址，可直接開啟該繳費網站。

# 

# 5\. 編輯

# &#x20;  將該筆資料帶回表單，可修改後重新儲存。

# 

# 6\. 刪除

# &#x20;  刪除該筆帳號備忘資料。

# 

# \------------------------------------------------------------

# 3\. 帳號密碼安全提醒

# \------------------------------------------------------------

# 

# 本 App 的帳號密碼備忘資料會以 Web Crypto API 加密後儲存在瀏覽器 IndexedDB。

# 

# 請注意：

# 1\. 不建議存放銀行、信用卡或金融相關的重要正式密碼。

# 2\. 若手機或電腦會借給他人使用，請避免存放敏感資訊。

# 3\. 匯出資料時，帳號密碼備忘也會一起匯出。

# 4\. 匯出的 JSON 備份檔請妥善保存，不要隨意傳給他人。

# 5\. 重要密碼建議使用專業密碼管理器。

#

# 五、紀錄分頁使用說明

# ============================================================

#

# 

# \------------------------------------------------------------

# 1\. 本月已繳總額

# \------------------------------------------------------------

# 

# 系統會統計本月已標記繳費的金額合計。

# 

# 例如本月已繳：

# \- 信用卡 5,000 元

# \- 電信費 999 元

# \- 保險費 2,000 元

# 

# 本月已繳總額會顯示 7,999 元。

# 

# \------------------------------------------------------------

# 2\. 總繳費紀錄筆數

# \------------------------------------------------------------

# 

# 顯示目前累積的繳費紀錄數量。

# 

# 每次按下：

# \- 已繳並建立下期

# \- 標記已繳

# 都會新增一筆繳費紀錄。

# \------------------------------------------------------------

# \------------------------------------------------------------

#

# 

# 如果超過 12 筆，會出現「查看全部」按鈕。

# 

# 按下後可展開全部紀錄，再按一次可收合回最近 12 筆。

# 

# \------------------------------------------------------------

# 4\. 清除紀錄

# \------------------------------------------------------------

# 

# 「清除紀錄」會刪除所有繳費紀錄。

# 

# 使用前請注意：

# 1\. 清除後無法從 App 內復原。

# 2\. 若要保留紀錄，請先到設定分頁匯出資料備份。

# 六、設定分頁使用說明

# ============================================================

# 

# 設定分頁集中放置通知、PWA 安裝、資料匯入匯出與備份提醒。

# 

# \------------------------------------------------------------

# 1\. 開啟繳費通知

# \------------------------------------------------------------

# 

# 按下「開啟繳費通知」後，瀏覽器會要求通知權限。

# 

# 允許後，App 可在開啟時檢查即將到期或逾期帳單，並發出提醒通知。

# 

# 注意：

# 1\. 瀏覽器通知不一定等於真正背景定時通知。

# 2\. 若 App 長時間沒有被開啟，通知可能不會準時檢查。

# 3\. 若需要穩定提醒，建議搭配「上傳 Google 日曆」。

# 

# \------------------------------------------------------------

# 2\. 測試通知

# \------------------------------------------------------------

# 

# 開啟通知權限後，可使用「測試通知」確認瀏覽器是否能正常跳出通知。

# 

# 如果測試通知沒有出現，請檢查：

# 1\. 瀏覽器通知權限是否被封鎖。

# 2\. 作業系統通知是否關閉。

# 3\. 手機是否開啟勿擾模式。

# \------------------------------------------------------------

# 3\. 加入主畫面

# \------------------------------------------------------------

# 

# 若瀏覽器支援 PWA，設定分頁會出現「加入主畫面」按鈕。

# 

# 加入後可像一般 App 一樣從手機或電腦桌面開啟。

# 

# 若沒有出現按鈕，可嘗試：

# 1\. 使用 Chrome、Edge 或支援 PWA 的瀏覽器。

# 2\. 手機版可從瀏覽器選單選擇「加入主畫面」。

# 3\. 確認網頁有透過本機伺服器或 HTTPS 開啟。

# 

# \------------------------------------------------------------

# 4\. 匯出資料

# \------------------------------------------------------------

# 

# 按下「匯出資料」會下載 JSON 備份檔。

# 

# 備份內容包含：

# 1\. 帳單資料

# 2\. 繳費紀錄

# 3\. 帳號密碼備忘

# 4\. 部分設定資料

# 

# 建議在以下情況先匯出：

# 1\. 換手機前

# 2\. 清除瀏覽器資料前

# 3\. 重新安裝 App 前

# 4\. 重要資料修改後

# 5\. 定期備份，例如每月一次

# \------------------------------------------------------------

# 5\. 匯入資料

# \------------------------------------------------------------

# 

# 按下「匯入資料」可選擇之前匯出的 JSON 檔。

# 匯入時請注意：

# 1\. 匯入會覆蓋目前裝置上的資料。

# 2\. 匯入前建議先匯出目前資料，避免覆蓋錯誤。

# 3\. 請只匯入由本 App 匯出的 JSON 備份檔。

# 4\. 不要匯入來路不明的檔案。

# 

# \------------------------------------------------------------

# 6\. 備份提醒

# \------------------------------------------------------------

# 

# 若系統偵測到很久沒有匯出備份，會出現備份提醒。

# 

# 提醒出現時，可按「立即匯出」下載最新資料。

# 七、建議使用流程

# ============================================================

# 

# 第一次使用建議照以下順序：

# 

# 1\. 到「帳單」分頁新增常用帳單。

# 2\. 每一筆帳單設定正確的帳單類型。

# 3\. 固定會繳的帳單設成「循環」。

# 4\. 偶爾才有的帳單設成「手動」。

# 5\. 到「帳號」分頁新增常用繳費網站與用戶編號。

# 6\. 到「設定」分頁開啟通知。

# 7\. 對重要帳單使用「上傳 Google 日曆」增加提醒穩定性。

# 8\. 新增完資料後，到「設定」分頁匯出一次備份。

# 

# 日常使用建議：

# 

# 1\. 每週打開 App 檢查一次提醒中或逾期帳單。

# 2\. 繳費後立即按下「已繳並建立下期」或「標記已繳」。

# 3\. 金額尚未確定時，可先留空，之後再編輯補上。

# 4\. 每月或資料大幅更動後，匯出 JSON 備份。

# 八、常見使用情境

# ============================================================

# 

# \------------------------------------------------------------

# 情境 1：常用信用卡，每個月都要繳

# \------------------------------------------------------------

# 

# 建議設定：

# \- 帳單類型：信用卡

# \- 帳單模式：循環

# \- 提醒天數：3 到 5 天

# 

# 繳費後按「已繳並建立下期」，系統會自動建立下個月帳單。

# 

# \------------------------------------------------------------

# 情境 2：很少用的信用卡，不一定每月有帳單

# \------------------------------------------------------------

# 

# 建議設定：

# \- 帳單類型：信用卡

# \- 帳單模式：手動

# 

# 有帳單時再新增或編輯該筆資料。

# 繳費後按「標記已繳」，系統只會記錄，不會自動產生下一期。

# 

# \------------------------------------------------------------

# 情境 3：手機費或網路費

# \------------------------------------------------------------

# 

# 建議設定：

# \- 帳單類型：電信費

# \- 帳單模式：循環

# \- 繳費方式：自動扣繳或手動繳費

# 

# 若是自動扣繳，也可以保留提醒，方便確認是否扣款成功。

# 

# \------------------------------------------------------------

# 情境 4：水電費

# \------------------------------------------------------------

# 

# 建議設定：

# \- 帳單類型：水電費

## 2026-06 帳號資料加密更新

- 「帳號」分頁新增主密碼解鎖區塊。
- 帳號資料使用 Web Crypto API：PBKDF2 + AES-GCM 加密後存入 IndexedDB 的 `encryptedAccounts`。
- 主密碼不會寫在 GitHub，也不會存在 IndexedDB；重新整理或按「重新鎖定」後需再次輸入。
- 舊版 `accounts` 明文資料會在第一次輸入主密碼時轉成加密資料。完成加密後，後續備份只會匯出 `encryptedAccounts`。
- 請務必記住主密碼；忘記後無法解密還原帳號資料。


## 更改帳號主密碼

帳號分頁解鎖後，可以按「更改主密碼」。系統會先使用目前已解鎖的帳號資料，再用新主密碼重新加密 `encryptedAccounts`。完成後，之後請使用新主密碼解鎖；忘記主密碼仍無法還原帳號資料。

## 2026-06 系統彈窗美化更新

- 將原生 `alert()`、`confirm()` 改為與整套系統一致的自訂彈窗。
- 匯入備份、刪除帳單、刪除帳號備忘、標記繳費、清除繳費紀錄等確認流程會使用卡片式確認視窗。
- 複製帳號與密碼改為底部 Toast 提示，減少操作中斷感。
- 彈窗支援手機版排版，並提供不同狀態視覺：提醒、成功、警告、危險操作。

## 介面更新：主密碼錯誤提示強化

帳號頁主密碼輸入錯誤時，現在會出現一致化的紅色提示卡、輸入框紅色狀態、輕微震動效果與底部 Toast，避免使用者不知道錯在哪裡。


# Google 日曆上傳功能

本版本已將帳單清單內原本產生 .ics 檔案的「加入行事曆」改為「上傳 Google 日曆」。

使用前請先到「設定」→「Google 日曆」貼上你的 OAuth Client ID，然後按「儲存 Client ID」。

Google Cloud 設定重點：

1. OAuth Client 類型請使用 Web application。
2. Authorized JavaScript origins 必須加入此網頁實際執行網址，例如本機測試時可加入 http://localhost:5500 或你的正式部署網域。
3. Google Calendar API 需在 Google Cloud 專案中啟用。
4. 第一次上傳時會跳出 Google 授權視窗，授權範圍為新增日曆事件。

事件內容：

- 新增到主要 Google 日曆 primary calendar。
- 事件時間預設為繳費截止日當天 09:00–09:30。
- 提醒時間使用帳單設定的「提前提醒天數」。
- 事件描述會包含帳單類型、應繳金額、最低應繳、繳費方式、繳費帳戶與備註。

# Google Drive 雲端備份（v27 新增）

# ============================================================

#

# 1. 到「設定」→「Google 服務」貼上你的 OAuth Client ID。

# 2. Google Cloud 需使用 Web application 類型 OAuth Client，並把此網頁網址加入 Authorized JavaScript origins。

# 3. 請確認已啟用 Google Drive API；若也要上傳帳單提醒，請同時啟用 Google Calendar API。

# 4. 按「備份到 Drive」會把目前 App 資料存到 Google Drive 的 App 專用資料夾 appDataFolder。

# 5. 按「從 Drive 還原」會讀取同一 Google 帳號中的雲端備份，確認後覆蓋目前瀏覽器資料。

# 6. appDataFolder 是 App 專用隱藏資料夾，備份檔通常不會出現在一般 Google Drive 檔案列表中。

# 7. 還原前建議先用「本機資料備份」匯出一份 JSON，避免誤覆蓋。
